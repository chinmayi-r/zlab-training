# zlab Training

Training materials and weekly reports for the [Princeton ZLab Warmup Program](https://github.com/zlab-princeton-internal/warmup-program).

## Structure

```
nano-vllm/
├── report.md       # full code walkthrough + theory (Days 1–8)
└── experiments.md  # step-by-step experiment scripts for Adroit

ai-scientist-v2/
├── report.md       # failure-mode deep dive + conceptual framing
├── experiments.md  # Adroit run guide (Sandbox $0 route, E1/E2 A/B)
├── ideas/          # E2 A/B: vague vs. pinned idea .md files
├── scripts/        # setup, Sandbox patch, config variants, log mining
└── slurm/          # E1/E2 batch scripts
```
